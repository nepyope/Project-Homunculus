# Finger Actuation and Exoskeleton Simplification

In this design, finger actuation occurs at three main joints:

1. **Metacarpophalangeal (MCP) Joint** – The base of each finger.
2. **Proximal Interphalangeal (PIP) Joint** – The second knuckle of each finger.
3. **Distal Interphalangeal (DIP) Joint** – The third knuckle of each finger.

The **Interphalangeal (IP) Joint** refers to the last knuckle, which is underactuated for all fingers **except for the thumb**.

### Design Simplification
In the full STL model, PIP joints vary in length (e.g., the pinky is shorter than the middle finger). However, this detail is **ignored** in the current design. A key advantage of **exoskeletons over gloves** is that they can **adapt to different finger lengths**, making precise joint length differences less critical.
